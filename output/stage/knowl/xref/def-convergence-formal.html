Definition 1.3.3. Convergence (formal).

The sequence \(\left \{ x_n \right \}\) converges to the limit \(L\) if and only if given any \(\epsilon \gt 0 \) there exists a postive integer \(N_{\epsilon}\) such that for all \(n \geq N_\epsilon\) the inequality \(|x_n - L | \lt \epsilon\) holds.
