    Section 1.3 Convergence

    Introductory and motivational remarks.
    🔗

    Definition 1.3.1. Convergence (informal).

    Let \(L \in \R\text{.}\) A sequence \(\left \{ x_n \right \}_{n=1}^\infty\) converges to the limit \(L\) if and only if as \(n\) increases, the elements of the sequence get closer and closer to \(L\text{,}\) or equivalently, the distance \(| x_n - L |\) gets closer and closer to \(0\text{.}\)
    🔗
    Other notation and language used to say that the sequence \(\left \{ x_n \right \}\) converges to the limit \(L\) is to say that \(x_n\) tends to \(L\) as \(n\) tends to \(\infty\text{,}\) or in symbolic form
    \begin{equation*} x_n \to L \text{ as } n \to \infty\text{,} \end{equation*}
    or
    \begin{equation*} \lim_{n \to \infty} x_n = L\text{,} \end{equation*}
    where the latter expression is read as "the limit, as \(n\) tends to \(\infty\text{,}\) is \(L\)".
    🔗
    If a sequence is not convergent then we say that it is divergent.
    🔗
    🔗
    Some sequences are divergent because their terms keep increasing in absolute value without any upper bound, in which case we can write
    \begin{equation*} y_n \to \infty \text{ as } n \to \infty \end{equation*}
    or
    \begin{equation*} y_n \to -\infty \text{ as } n \to \infty\text{.} \end{equation*}
    The first of these says that the term $y_n$ increase in positive value without any upper bound, and the second says that the terms $y_n$ get large and negative without any lower bound. However although this notation and phrasing is used quite commonly we should be careful. Such sequences are still divergent, and we should certainly not treat \(\infty\) (whatever it is really) as a number like any other.
    🔗

    Example 1.3.2. A convergent sequence.

    It is not too hard to appreciate the convergence of some simple sequences, for instance
    \begin{equation*} \lim_{m \to \infty} \frac{1}{m} = 0\text{.} \end{equation*}
    The numbers \(\frac{1}{m}\) are getting smaller and smaller and moreover they are getting arbitrarily small, i.e. given any small number \(\epsilon\text{,}\) eventually the fractions \(\frac{1}{m}\) will get smaller than \(\epsilon\text{.}\)
    🔗
    🔗
    While the definition given in Definition 1.3.1 allows us to understand the idea of convergence, a more rigorous formal definition is needed to prove results about the concept of convergence.
    🔗

    Definition 1.3.3. Convergence (formal).

    The sequence \(\left \{ x_n \right \}\) converges to the limit \(L\) if and only if given any \(\epsilon \gt 0 \) there exists a postive integer \(N_{\epsilon}\) such that for all \(n \geq N_\epsilon\) the inequality \(|x_n - L | \lt \epsilon\) holds.
    🔗
    🔗
    This definition is important, and forms the basis of much of the following material on the theory of sequences. We shall be using the definition in two main ways.
    1. To prove that certain given sequences either do or do not converge to a given limit.
      🔗
      🔗
    2. To prove theorems about the convergence of sequences.
      🔗
      🔗
    We will only do a few examples of type 1 work, and a lot more of type 2 work.
    🔗
    You should spend enough time thinking about this definition, and examining the way it is used in this chapter, to really get a feel for what it is saying and how it works.
    🔗
    It is worth considering the compact form of the definition expressed in logical symbols, i.e.
    \begin{equation*} \lim_{n \to \infty} x_n = L \Leftrightarrow \forall \epsilon \gt 0 \,\, \exists N \quad n \geq N \Rightarrow |x_n - L | \lt \epsilon\text{.} \end{equation*}
    🔗

    Checkpoint 1.3.4. Recalling the formal definition.

    Think of ways to turn this into more colloquial English, while still retaining the mathematical precision needed. One version is given in the answer below.
    🔗
    Answer.
    For every given measure of closeness, \(\epsilon\text{,}\) to the limit, \(L\text{,}\) a point, \(N\text{,}\) can be found so that the ALL the sequence elements after this point (\(n \geq N\)) are within a distance \(\epsilon\) of \(L\text{,}\) i.e. \(|x_n - L | \lt \epsilon\text{.}\)
    🔗
    🔗
    🔗
    🔗
    The definition and the roles of the parameters in the definition can make more sense when one pictures a graphical plot of the sequence elements decorated with the definition parameters, as in Figure 1.3.5.
    🔗
    Think about the effect of varying the value of \(\epsilon\) in Figure 1.3.5. Decreasing \(\epsilon\) will narrow the band around the limit, while increasing \(\epsilon\) will widen the band around the limit. As the band narrows we will probably have to choose larger and larger values of \(N\) to satisfy the convergence definition.
    🔗
    Let’s return to the previous example to see the formal definition working.
    🔗

    Example 1.3.6. A convergent sequence.

    \begin{equation*} \lim_{n \to \infty} \frac{1}{n} = 0\text{.} \end{equation*}
    🔗
    Solution.
    As this is our first example working with the formal definition we shall provide a lot of discussion and explanation in this solution.
    🔗
    In the notation given in the formal definition, Definition 1.3.3, we have \(x_n = 1/n\) and \(L=0\) here. Since we have to demonstrate that, given any \(\epsilon \gt 0\text{,}\) there exits a value \(N\text{,}\) we should work with a general \(\epsilon\text{,}\) not any specific value. It is customary to do this by starting our argument with the following phrase.
    🔗
    Let \(\epsilon \gt 0\) be given.
    🔗
    The \(N\) that we have to find is such that, if \(n \geq N\text{,}\) then \(|x_n - L | \lt \epsilon \text{.}\) So let us examine this inequality in more detail.
    \begin{align*} \amp |x_n - L | \lt \epsilon ,\\ \Leftrightarrow \, \, \amp \frac{1}{n} \lt \epsilon, \\ \Leftrightarrow \, \, \amp n \gt \frac{1}{\epsilon}. \end{align*}
    🔗
    So let us choose \(N\) to be any natural number satisfying \(N \gt 1/\epsilon\text{.}\) That such a number exists is due to the Archimedean property of the natural and real numbers, i.e. that there is no largest natural or real number.
    🔗
    Having chosen such a value for \(N\) we note that it now satisfies the property
    \begin{equation*} n \geq N \Rightarrow n \gt \frac{1}{\epsilon} \Leftrightarrow |x_n - L | \lt \epsilon \text{.} \end{equation*}
    🔗
    This shows that the formal definition of convergence is satisfied, and so we have proved that \(1/n \to 0\) as \(n \to \infty\text{,}\) as claimed.
