    Section 2.1 Initial definitions

    Definition 2.1.1. Sequence.

    A sequence is a list of elements, indexed by the positive integers.
    🔗
    In these notes we will almost exclusively be considering sequences of real numbers. But mathematicians could talk of sequences of any sort of mathematical object.
    🔗
    We can use a single letter, \(x\) say, decorated with an index subscript, to denote the elements of a sequence, as in
    \begin{equation*} x_1, x_2, x_3, \ldots\text{.} \end{equation*}
    This sequence could be denoted as a whole by the notation \(\left \{ x_n \right \}_{n=1}^{\infty}\) or just simply \(\left \{ x_n \right \}\text{,}\) if the indexing is understood.
    🔗
    Variations might be to use the non-negative integers for the indexing, so the first element of the sequence would be \(x_0\) rather than \(x_1\text{.}\) Or perhaps start the indexing at some other integer.
    🔗
    🔗
    This definition will be sufficient for our purposes, but more formal versions are possible. Some authors would define a sequence of real numbers as a function \(f: \Z^{+} \to \R\text{,}\) i.e. \(f\) is the function from the index values to the corresponding sequence elements. So then the list/sequence of elements would be
    \begin{equation*} f(1), f(2), f(3), \dots\text{.} \end{equation*}
    An advantage of this would be to integrate our definitions with the already existing concept of a mathematical function, and not have to rely on introducing a new concept of list.
    🔗

    Example 2.1.2. Some example sequences.

    These examples and the other ones in this section show some basic sequences and different ways to use the notation for the sequence element and index.
    🔗
    1. The sequence of positive integers themselves, \(1, 2, 3, 4, \dots \text{.}\) We could denote this as \(\left \{ z_m \right \}_{m=1}^\infty\text{,}\) where the defining rule is simply, for \(m \geq 1\)
      \begin{equation*} z_m = m\text{.} \end{equation*}
      🔗
      🔗
    2. The Fibonacci sequence
      \begin{equation*} 1, 1, 2, 3, 5, 8, \dots \end{equation*}
      denoted \(\left \{ f_n \right \}_{m=1}^\infty\text{,}\) where the rule is
      \begin{equation*} f_1 = 1, \, \, f_2 = 1, \, \, \text{ and for all } m \geq 3 \quad f_m = f_{m-1} + f_{m-2}\text{,} \end{equation*}
      i.e. each element is the sum of the previous two elements. This type of definition for a sequence, where each element is defined in terms of previous elements, is called a recurrence relation.
      🔗
      🔗
    3. The sequence of odd positive integers \(1, 3, 5, 7, \dots\text{,}\) denoted by \(\left \{ a_j \right \}_{m=1}^\infty\text{,}\) defined by the rule
      \begin{equation*} a_j = 2j - 1\text{.} \end{equation*}
      🔗
      🔗
    4. The sequence of prime numbers
      \begin{equation*} 2, 3, 5, 7, 11, 13, \dots \end{equation*}
      denoted by \(\left \{ p_m \right \}_{m=1}^\infty\text{.}\) Unfortunately there is no easy to state formula known for the \(m^{\text{th}}\) prime. We can specify an algorithm to find it, and various asymptotic results exist that can approximate the value of it. It can be proved that there an infinite number of primes, so the indexing declaration is valid. See more on this in your Number Theory and Abstract Algebra module next year.
      🔗
      🔗
    🔗
    🔗

    Definition 2.1.3. Arithmetic sequences.

    An arithmetic sequence is one with a constant common difference between successive elements. So we can write such a sequence as
    \begin{equation*} a, a+d, a+2d, a+3d, \dots\text{,} \end{equation*}
    or \(\left \{ a_n \right \}_{n=1}^{\infty}\text{,}\) where \(a_n = a+ (n-1)d\text{,}\) i.e. \(a\) is the initial element and \(d\) the common difference.
    🔗
    🔗

    Definition 2.1.4. Geometric sequences.

    An geometric sequence is one with a constant common ratio between successive elements. So we can write such a sequence as
    \begin{equation*} a, ar, ar^{2}, ar^{3}, \dots\text{,} \end{equation*}
    or \(\left \{ g_n \right \}_{n=1}^{\infty}\text{,}\) where \(g_n = ar^{n-1}\text{,}\) i.e. \(a\) is the initial element and \(r\) the common ratio.
    🔗
    🔗

    Example 2.1.5. Arithmetic and geometric sequences.

    1. The sequence of odd positive integers, \(1, 3, 5, 7, \dots\) is arithmetic. It is given by \(\left \{ a_n \right \}_{n=1}^{\infty}\) where \(a_n = 1 + (n-1)2 = 2n -1\text{.}\)
      🔗
      🔗
    2. The sequence of powers of \(1/2\text{,}\) which begins \(1, 1/2, 1/4, 1/8, \dots \) is geometric. It is given by
      \begin{equation*} h_n = \left ( \frac{1}{2} \right )^{n-1} = \frac{1}{2^{n-1}}, \end{equation*}
      with initial element \(1\) and common ratio \(1/2\text{.}\)
      🔗
      🔗
    3. A negative example. The sequence of reciprocals of the squares, \(\left \{ s_n \right \}_{n=1}^{\infty}\text{,}\) where \(s_n = 1/n^2\) is neither arithmetic nor geometric.
      🔗
      🔗
    4. Are there any sequences that are both arithmetic and geometric?
      🔗
      🔗
    5. Compound interest awarded on investments, or charged on loans, provide examples of geometric sequences. Suppose a bank overs a savings account with an annualy compounded interest rate of \(r \%\) per year on an initial deposit of \(£P\text{.}\) Then the value, \(v_n\text{,}\) of the deposit at the beginning of the \(n^{\text{th}}\) year is given by
      \begin{equation*} v_n = P \left ( 1+ \frac{r}{100} \right )^{n-1}\text{.} \end{equation*}
      🔗
      🔗
