    Section 4.1 Limiting values of functions

    We have met the concept of a limit in the context of sequences and series. The concept is also useful when discussing real-valued functions. Let \(a\) and \(l\) be two real numbers. Informally we say that the function \(f\) tends to the limit \(l\) as \(x\) tends to \(a\) if the value \(f(x)\) gets closer and closer to \(l\) as \(x\) gets closer and closer to \(a\text{.}\) We can represent this symbolically as
    \begin{equation*} \lim_{x \to a} f(x) = l , \end{equation*}
    which we read as ‘the limit, as \(x\) tends to \(a\text{,}\) of \(f(x)\) is equal to \(l\)’. Alternatively we can write
    \begin{equation*} f(x) \to l \text{ as } x \to a, \end{equation*}
    which we read as ‘\(f(x)\) tends to \(l\) as \(x\) tends to \(a\)’.
    🔗
    Notice that this description makes no reference to the actual value (if any) of the function \(f\) at \(a\text{.}\) The concept of limit only refers to the behaviour of \(f\) as it approaches some limiting point \(a\text{.}\)
    🔗
    This definition is not sufficiently rigorous though. For instance, as the diagram in figure Figure 4.1.1 illustrates, a function may have different limits depending on the direction from which \(x\) approaches \(a\text{.}\)
    🔗
    If this situation arises then we can refer separately to the two different limits as follows. The limit of \(f\) as \(x\) tends to \(a\) from the left is written as
    \begin{equation*} \lim_{x \to a^-} f(x), \end{equation*}
    and the limit of \(f\) as \(x\) tends to \(a\) from the right is written as
    \begin{equation*} \lim_{x \to a^+} f(x). \end{equation*}
    🔗
    Although it is not an element of the real numbers \(\mathbb{R}\) we can admit the concept of infinity (\(\infty\)) into this definition as it will allow us to describe the behavior of functions in the following way. If a function \(f\) grows without bound as \(x\) approaches \(a\) then we can write
    \begin{equation*} \lim_{x \to a} f(x) = \infty. \end{equation*}
    For example
    \begin{equation*} \lim_{x \to 0^-} \frac{1}{x} = -\infty, \end{equation*}
    and
    \begin{equation*} \lim_{x \to 0^+} \frac{1}{x} = \infty, \end{equation*}
    If the values of a function \(f\) approach some limit \(l\) as the argument \(x\) gets larger and larger then we could write
    \begin{equation*} \lim_{x \to \infty} f(x) = l. \end{equation*}
    For example
    \begin{equation*} \lim_{x \to +\infty} \frac{1}{x} = 0, \end{equation*}
    and
    \begin{equation*} \lim_{x \to -\infty} \frac{1}{x} = 0. \end{equation*}
    🔗
    These limiting values of the function \(y=\frac{1}{x}\) can be appreciated from its graph shown in figure Figure 4.1.2.
    🔗
    To calculate and work with limiting values of functions we can use the standard techniques that we introduced when dealing with limits of sequences and series. We have the following theorem
    🔗

    Theorem 4.1.3. Algebra of limits for function values.

    Let \(l,m \in \mathbb{R}\) and suppose that \(\lim_{x \to a} f(x) = l\) and \(\lim_{x \to a} g(x) = m\text{,}\) then
    \begin{equation*} \begin{aligned} \lim_{x \to a} (\alpha f(x) + \beta g(x)) &= \alpha l + \beta m , \\ \lim_{x \to a} \left ( f(x)g(x) \right )&= lm , \\ \lim_{x \to a} \frac{f(x)}{g(x)} &= \frac{l}{m} \end{aligned}\text{.} \end{equation*}
    For the last quotient case we would need the additional assumption that \(m \neq 0\) and that \(g(x)\) is non-zero in some interval around \(a\text{.}\)
    🔗
    🔗
    Of particular use is l’Hopital’s rule. This is used to evaluate the limit, \(\lim_{x \to a} \frac{f(x)}{g(x)}\text{,}\) of a quotient of functions \(f\) and \(g\text{.}\) Sometimes these limits can not be evaluated because it works out to some indeterminant form, i.e \(\frac{0}{0}, \frac{\infty}{\infty}\text{.}\) In these cases we can differentiate both functions and then look at the limit of the resulting quotient. If this new limit exists then the rule says that it is equal to the original limit.
    🔗

    Theorem 4.1.4. l’Hopital’s rule.

    If \(\lim_{x \to a} f(x) = \lim_{x \to a} g(x) = 0\) or \(\lim_{x \to a} f(x) = \lim_{x \to a} g(x) = \infty\) then providing the limit exists
    \begin{equation*} \lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)} , \end{equation*}
    where \(f'\) and \(g'\) are the derivatives of \(f\) and \(g\text{.}\)
    🔗
    🔗
    It may be necessary to apply l’Hopital’s rule a number of times (i.e. taking second or third derivatives etc) in order to convert the original indeterminate limit into a determinate one.
    🔗

    Example 4.1.5.

    The following examples illustrate the use of these techniques.
    🔗
    1. \begin{equation*} \lim_{x \to \infty} \frac{3x + 1}{2x} = \lim_{x \to \infty} \frac{3 + \frac{1}{x}}{2} = \frac{3}{2}. \end{equation*}
      🔗
      🔗
    2. \begin{equation*} \lim_{x \to 0} \frac{\sin{x}}{x} = \lim_{x \to 0} \frac{\cos{x}}{1}=1. \end{equation*}
      🔗
      🔗
    3. \begin{equation*} \lim_{x \to \infty} \frac{x +1}{x} = \lim_{x \to \infty} \frac{1 + \frac{1}{x}}{1} = 1. \end{equation*}
      🔗
      🔗
    4. \begin{equation*} \lim_{x \to 0} \frac{\sin{2x}}{3x} = \lim_{x \to 0} \frac{2\cos{2x}}{3} = \frac{2}{3}. \end{equation*}
      🔗
      🔗
    5. \begin{equation*} \lim_{x \to 0} \frac{e^x - e^{-x}}{x} = \lim_{x \to 0} \frac{e^x + e^{-x}}{1} = 2. \end{equation*}
      🔗
      🔗
    6. \begin{equation*} \lim_{x \to 0} \frac{\sin{x} - x}{x^3} = \lim_{x \to 0} \frac{\cos{x} - 1}{3x^2} = \lim_{x \to 0} \frac{-\sin{x}}{6x} = \lim_{x \to 0} \frac{-\cos{x}}{6} = \frac{-1}{6}. \end{equation*}
      🔗
