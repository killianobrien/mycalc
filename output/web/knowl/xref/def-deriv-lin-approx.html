Definition 4.4.5. The derivative.

The derivative, \(f'(a)\text{,}\) is the unique number that provides the linear approximation \(f(a) + f'(a) k\) for the value \(f(a+k)\) with the property that the error term \(k \epsilon(k)\) has the convergence property that \(\epsilon(k) \to 0\) as \(k \to 0\text{.}\)
